# 📚 Estudos Kubernetes e OpenShift (Red Hat)

Este repositório foi criado com o objetivo de armazenar meus arquivos, manifestos e anotações de estudo baseados no curso da **Red Hat**.

## 🛠️ Tecnologias Abordadas

- **Kubernetes (K8s)**: Orquestração de contêineres.
- **Minikube**: Execução de clusters Kubernetes localmente para testes e desenvolvimento.
- **Red Hat OpenShift**: Plataforma de contêineres corporativa baseada em Kubernetes.

## 🎯 Objetivo

Documentar meu progresso de aprendizado e desenvolvimento durante o curso, servindo como um portfólio de estudos práticos e material para consultas futuras.
